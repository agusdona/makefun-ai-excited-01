# The Koi That Folded the Sky

A giant golden koi leaps through an origami-folded night sky above a faceted paper city, with a full moon, flying cranes, and a bold judge banner. The image is drawn from scratch as a deterministic 1024x1024 PNG using Python's standard library only.

Run it with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The fixed random seed and deterministic PNG encoding make repeated runs byte-identical.
